# 简易数据模板编写说明

数据模板不需要额外的配置页、隐藏工作表或元数据头。把模板当作普通的 Excel、CSV 或 Word 文件编辑，在需要替换的位置写入标记即可。模板名称使用文件名，模板版本统一为 `1.0.0`。

## 标记语法

| 标记 | 作用 | 数据位置 |
| --- | --- | --- |
| `{{period}}` | 替换一个值 | `template.values.period` |
| `{{items.name}}` | 按模板行展开 | `template.tables.items` 的 `name` 列 |
| `{{items.name|column}}` | 按模板列展开 | `template.tables.items` 的 `name` 列 |
| `{{items|matrix}}` | 展开完整的 M×N 矩阵 | `template.tables.items` 的全部 `Rows` 和 `Columns` |

变量名、集合名和字段名使用小写字母、数字和下划线。脚本负责查询数据、转换类型、计算汇总和准备表格；模板只负责排版和放置标记。

## Excel 模板

在普通 Excel 中直接编辑 `.xlsx` 文件：

1. 在第一行输入表头和固定内容；
2. 在需要逐条输出的样板行中放入 `{{items.字段}}`；
3. 需要横向输出时，在样板列中放入 `{{items.字段|column}}`；
4. 日期时间单元格预先设置为日期-时间格式，例如 `yyyy/mm/dd-hh:mm:ss`；
5. 保存文件后导入应用。

如果行数和列数都需要动态变化，可以把 `{{items|matrix}}` 放在一个单元格中。它会从该单元格开始展开完整矩阵，模板中位于矩阵上方和下方的固定内容会保留。

例如加班明细模板可以写成：

```text
加班人姓名 | 加班人编号 | 开始时间 | 结束时间 | 加班说明
唐国利     | 00000399   | {{items.start_time}} | {{items.end_time}} | {{items.description}}
```

包含 `{{items.start_time}}` 的行会按 `items` 表格中的每一行复制。XLSX 同一个工作表暂不同时使用行循环和列循环；可以把两种布局放在不同工作表中。

## CSV 模板

CSV 模板是普通 UTF-8 文本，不要添加配置头：

```csv
姓名,工时
{{items.name}},{{items.hours}}
横向,{{items.name|column}}
```

行循环会复制整行；列循环会复制标记所在字段。CSV 输出仍然会自动处理逗号、引号、换行和公式前缀转义。

CSV 中的矩阵标记必须独占一整行：

```csv
固定表头
{{items|matrix}}
固定表底
```

矩阵行会被替换成数据表的所有列，前后的固定行保持不变。

## Word 模板

在 `.docx` 表格的样板行中使用 `{{items.field}}`，在样板单元格中使用 `{{items.field|column}}`。普通段落可以使用 `{{variable}}`。循环标记必须位于表格内，不能放在合并单元格中。

需要动态行数和列数时，让 `{{items|matrix}}` 独占一个仅含该单元格的表格行。矩阵行前后的固定表格行会保留。

## 脚本数据

脚本先通过模板列表获取模板 ID 和绑定描述，再提交 `values` 与 `tables`。模板不会执行表达式、条件判断或计算；缺少绑定数据、字段不存在或数据类型错误时，导出会失败并返回结构化诊断。

导入校验失败的文件不会进入可用模板目录，也不能被脚本分发或导出。
