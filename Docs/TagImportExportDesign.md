# 标签导入导出设计

最后更新：2026-08-22

## 1. 目标与入口

标签导入导出用于在不同 DiaryApp 数据库之间迁移标签定义和可选的 Tracker 标签规则，不替代数据库备份，也不迁移工作记录、数据模板或 Tracker 凭据。

操作入口固定在“标签编辑器”页面左侧标签区域，提供“导入”和“导出”按钮。导出时在标签编辑器内部显示标签选择遮罩区，默认全选并支持全选、清空和逐项选择；至少选择一个标签后才能继续选择保存位置。选择区不再嵌套打开第二层 overlay，避免高 DPI 下重复缩放或裁切。操作前先校验并保存页面中尚未提交的标签、附加字段和 Tracker 规则修改；完成后保持标签编辑器打开并刷新标签与规则视图。

## 2. 文件格式

标签包使用扩展名 `.diarytags` 的版本化 JSON：

- `format` 固定为 `diary-tags`；
- `version` 当前为 `1`；
- 最大文件大小为 4MB；
- 标签和 Tracker 使用仅在包内有效的 `tag-N`、`tracker-N` 引用键，不导出数据库标签 ID 或本地 Tracker InstanceId；
- Tracker 描述只包含插件类型和显示名称，不包含地址、用户名、Token、API Key、代理或其他连接配置。

## 3. 标签数据

仅所选标签参与导出；每个所选标签导出：

- 名称、颜色和一级/二级层级；
- 字符串键值元数据；
- 附加字段的 `FieldKey`、显示名称、类型、说明、排序、选项、默认值和启用状态。

禁用标签仍然参与导出，但标签包不记录标签禁用状态。新建标签和更新同名标签在导入后均为启用状态；如果本地同名标签原本禁用，预览必须明确提示“将重新启用”。选择跳过该标签时保留本地原状态。

标签包不包含工作记录、工作记录标签关系、附加字段值、数据模板、最近使用记录或统计数据。

未选标签及其元数据、附加字段和 Tracker 规则不会写入共享包。停用标签仍可在选择窗口中选中，并明确显示停用状态。

## 4. 标签冲突

导入按区分大小写的标签名称匹配本地标签：不存在则新增，存在则更新颜色、层级和元数据，并启用标签。附加字段按全局大小写不敏感的 `FieldKey` 匹配：

- 同一标签且类型一致时更新可变属性；
- 默认值随字段定义更新；空默认值保持“不预填”，`Choice` 默认值必须属于包内候选列表；
- 字段已属于其他标签或类型不一致时标记为冲突；
- 仅大小写不同的本地标签不能自动合并；
- 有冲突的标签默认不选中，未解决冲突不能写入；
- 导入不会删除包中未出现的本地标签、元数据键或字段定义。

标签和附加字段在数据库事务中写入，任何标签定义写入失败都回滚本批标签变更。

## 5. Tracker 映射

包内每个来源 Tracker 按“插件类型 / 显示名称”显示。导入时只列出相同插件类型的本地实例，并始终提供“不关联”：

- 没有同类型实例时只能不关联；
- 只有一个同类型实例时可选关联或不关联；
- 有多个实例时由用户选择目标实例；
- 类型和显示名称均精确匹配时默认选择该实例；
- 映射按来源 Tracker 统一设置，不对每个标签重复询问。

不关联时标签照常导入，对应规则全部跳过。包内 Tracker 名称只用于提示和默认匹配，不作为本地稳定身份。

## 6. Tracker 规则验证

规则映射到本地实例后必须重新验证，不能直接写入：

1. 检查规则字段是否受该 Tracker 支持、值格式是否合法、必填目标是否缺失；
2. 检查规则引用的标签是否在本次导入选择中；
3. 使用目标实例的本地有效目标集合检查值是否存在或已失效；
4. 无法读取目标实例数据时标记为“无法验证”，不能当作有效规则。

RedMine 当前验证 `ActivityId` 和 `IssueId`：ID 必须为正整数，至少配置一个目标；Activity 必须存在且未失效，Issue 必须存在且未禁用/失效。导入预览显示有效、无效、无法验证数量，以及对应标签和具体原因。

仅有效规则写入目标实例；无效、无法验证和未关联规则均跳过。Tracker 规则失败不回滚已经成功提交的标签定义，但导入结果必须分别汇总新增、更新、重新启用、规则导入和规则跳过数量。

## 7. 安全边界

- 不导出或记录任何 Tracker 凭据和服务地址；
- 不按来源 InstanceId 自动关联本地实例；
- 不执行包内代码或动态类型；
- 拒绝未知格式版本、重复标签/Tracker 键、无效枚举、重复附加字段键、非法字段默认值和越界标签引用；
- 文件选择、预览和最终确认都在标签管理页面发起。

## 8. 测试要求

- 导出选择区默认全选，支持清空和逐项恢复选择，没有选择时不能继续；
- Windows 150% DPI 最大化窗口下，标题、说明、三个以上标签、取消和保存位置按钮及选择区四边应完整可见；
- 只导出所选标签及其元数据、附加字段和 Tracker 规则，未选标签不进入包；
- 禁用标签可导出，JSON 不包含标签禁用状态，导入后标签启用；
- 标签颜色、层级、元数据以及含默认值的附加字段定义可以往返；旧版 version 1 包缺少 `defaultValue` 时按空值导入；
- 字段被其他标签占用或类型不一致时预览为冲突；
- Tracker 包只包含类型和名称，不包含本地 InstanceId 或凭据；
- 无同类型、单实例和多实例映射行为正确；
- 非法、不存在和无法验证的 Tracker 规则不会写入；
- 标签事务失败时回滚，Tracker 规则失败不破坏已提交标签；
- SQLite/PostgreSQL provider 的导入结果保持一致。
