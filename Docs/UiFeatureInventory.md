# DiaryApp UI 功能清单

## 1. 文档范围

本文按 2026-08-22 当前工作区源码盘点 DiaryApp 已实现的桌面 UI，作为功能入口、测试设计和回归检查的索引，不表示未来规划，也不等同于所有功能在任意配置下都会显示。

界面和操作可能受以下条件影响：

- 数据库是否连接成功，以及当前使用 SQLite 还是 PostgreSQL。
- 调查功能、调查者模式和开发者功能是否开启。
- Tracker 插件及具体实例是否已安装、启用、配置有效并成功加载。
- 当前工作项是否已经保存、是否已上传远程 Tracker、是否来自只读迁移数据。
- 脚本是否编译/加载成功，以及声明的 Scope、入口类型和目标是否匹配。
- 部分更新、备份、还原和文件导出能力是否受运行目录、操作系统及 provider 能力限制。

本文不记录服务器地址、账号、API Key、Token 等敏感配置值。

## 2. 主窗口、导航和全局外壳

### 2.1 主导航

| 页面 | 功能 | 显示条件 |
| --- | --- | --- |
| 日记记录 | 按日期维护工作事项、标签、本地备注和 Tracker 工时 | 固定显示；数据库不可用时显示恢复入口 |
| 事项查询 | 按日期、文字、标签和优先级查询历史事项 | 固定显示 |
| 统计工具 | 按周、月、季度、年或自定义范围汇总工时 | 固定显示 |
| 调查工具 | 向局域网受访节点发起兼容或扩展工时调查 | 开启调查功能并作为调查者时显示 |
| 脚本管理 | 管理、编辑、运行、诊断和共享本机脚本 | 开启“显示开发者功能”时显示 |
| Tracker 管理页 | 由 Tracker 实例提供，例如 Redmine 管理页 | 实例启用、加载成功且插件提供管理页时动态显示 |

- 左侧导航栏支持展开和折叠。
- 固定页面和动态 Tracker 页面按最终顺序绑定 `Alt+1`、`Alt+2` 等快捷键。
- 保存程序设置或 Tracker 设置后，导航页会按最新配置重新构建。
- 当前页面在主内容区展示，导航切换会调用页面的显示/隐藏生命周期。

### 2.2 标题栏和应用菜单

- 应用图标菜单：关于、最大化、最小化、重启程序、退出；正式发布版且随包文档存在时，在“关于”后显示“用户手册”。
- 版本按钮：显示版本号和详细信息 Tooltip；上下文菜单可直接检查更新、复制版本号或复制详细信息。
- 标题栏主题按钮用于在亮色和暗色之间快速切换；程序设置中的默认主题还可选择跟随系统。
- 设置菜单：程序设置、标签设置、模板设置、数据模板、Tracker 设置、导入脚本扩展共享包。
- 自定义标题栏保留强调性的反差配色；状态栏跟随主内容的亮色/暗色主题，使用中性底色、边框和悬停反馈展示日期、机器、用户及后台任务入口。

### 2.3 托盘

- 托盘菜单提供版本信息、关于和退出。
- 可从托盘恢复主窗口。
- “始终显示托盘”决定程序运行期间是否持续显示托盘图标。
- “隐藏到托盘”开启时，关闭主窗口会隐藏而不是直接退出。

### 2.4 状态栏

- 打开项目源代码入口。
- 显示当前日期，并可弹出只读日历。
- 显示当前计算机名和用户名。
- 有后台任务时显示任务状态图标和“查看后台任务”入口。
- 当前后台任务入口只有状态占位，任务进度预览仍未实现。

### 2.5 首次使用引导

- 说明本地记录、远程同步和日常效率三个基本概念。
- 支持“稍后再看”“打开数据库设置”“开始记录”。
- 支持勾选“以后不再显示此引导”。
- 可从程序设置手动重新打开引导。

## 3. 日记记录

### 3.1 数据库不可用状态

- 显示数据库连接不可用及具体状态信息。
- 明确提示连接失败不会删除本地记录。
- 提供“重试连接”“打开数据库设置”“导出诊断日志”。
- 数据库恢复后重新进入正常日记编辑界面。

### 3.2 日期和复制入口

- 左侧固定显示当前锚点所在的一周，点击日期进行单日选择；今天使用浅色强调底与描边，当前选中日期使用主色高亮背景，两种状态可同时出现。
- 左右箭头、PageUp/PageDown 和鼠标滚轮逐周浏览；浏览周历不改变当前选中日期。
- 左键点击月份标题打开完整月历，用于跨月、月份和年份定位；完整月历不承载上下文操作。
- “回到今天”，快捷键 `Ctrl+T`。
- “复制昨天”：复制上一天的本地工作事项。
- “复制最近”：在当前日期之前近一年范围内找到最近一条记录并复制。
- “复制整天”：通过对话框选择源日期，将源日期全部事项复制到当前目标日期。
- 复制仅保留本地字段、标签和附加字段，不复制远程 Tracker 绑定及上传状态。
- 复制、新建和模板替换前会收敛当前编辑状态；有内容的草稿先持久化，避免切换造成数据丢失。

### 3.3 日历上下文菜单

上下文操作位于紧凑周历外层，并按入口对应的时间范围分组：

- 右键日期会先选中目标日期，再显示单日、本周和上周操作，包括同步本日/本周工时、统计/调查本周工时，以及对应范围的脚本。
- 右键月份标题显示本月、本季度和本年度操作，包括同步本月工时、统计/调查入口及对应范围的脚本；操作范围以当前浏览月份为准。
- 完整月历仅用于日期选择、跨月和年月定位，不提供上下文菜单。
- 脚本菜单仅显示目标类型匹配且当前可运行的脚本。

### 3.4 当日汇总和事项列表

- 显示当日总工时和已上传 Tracker 工时。
- 批量同步入口，快捷键 `Ctrl+Shift+U`。
- 列表显示事项标题、优先级、工时、标签颜色和本地/远程状态摘要。
- 支持选择当前事项并在右侧编辑。
- 无选中项时显示空状态。

### 3.5 工作项通用字段

- 日期：日历选择，以及“使用今天”“使用昨天”“使用明天”；日期输入与标题、耗时输入共享同一左边缘。
- 标题：单行文本编辑。
- 耗时：使用单一输入框编辑，支持 0 至 24 的数字小时以及 `30m`、`1h30m`、中文时间表达式；按 `Enter` 或移开焦点应用，按 `Esc` 恢复，格式说明通过 Tooltip 提示。
- 快捷耗时：15 分钟、30 分钟、1 小时、2 小时、4 小时、8 小时、清零。
- 优先级：枚举选择。
- 本地备注：多行文本，仅保存在本地工作项。

### 3.6 标签

- 从已启用标签中添加标签，最近使用的主标签优先展示。
- 删除当前工作项上的标签。
- 主标签和次标签受标签层级及主标签数量规则约束。
- 标签颜色显示在事项列表和编辑器中。
- 标签带附加字段时可打开字段编辑/查看对话框。
- 添加标签可触发 Tracker 标签自动化和应用自动化脚本。

### 3.7 附加字段的类型化编辑器

附加字段按字段类型显示不同控件，不再统一使用单行文本框：

| 字段类型 | 工作项编辑控件 |
| --- | --- |
| 单行文本 | 单行文本框 |
| 多行文本 | 可换行文本框 |
| 整数 | 整数数值框 |
| 小数 | 小数数值框 |
| 布尔值 | 复选框，并显示当前布尔语义 |
| 日期 | 日期选择器 |
| 时间 | 时间选择器和清空按钮 |
| 日期时间 | 日期选择器、时间选择器和清空按钮 |
| 单选项 | 选项选择器和清空按钮 |

- 字段按来源标签分组，显示字段标签、FieldKey 和说明 Tooltip。
- 可选字段允许留空；保存前执行类型和值校验。
- 日期时间编辑器为日期、时间和清空操作保留独立布局空间，避免在最小对话框宽度下互相覆盖。
- 停用字段如果已有历史值仍会显示，并标注“已停用，仅供查看”；该字段单独只读，不影响其他启用字段保存。
- 普通事项因 Tracker 同步而锁定时不允许修改附加字段；迁移工具导入的只读事项不显示附加信息入口，因为旧版本数据源不包含该能力。

### 3.8 Tracker 编辑区域和同步状态

- 每个启用且支持编辑器扩展的 Tracker 实例提供独立 Tab。
- Tracker Tab 内显示实例自己的 Issue、活动或其他绑定字段。
- 展示最近同步结果、错误、尝试时间和状态摘要。
- 支持未尝试、等待、成功、失败、结果不确定等状态。
- 已成功上传的 Tracker 记录不允许重复上传。
- 导入或迁移产生的只读事项仍可切换 Tracker Tab 查看已有绑定，但 Issue、活动、刷新等 Tracker 内容区整体禁用，不允许修改本地关联。
- 远程提交成功但本地状态保存失败时标记为“结果不确定”，避免自动重试造成重复写入。

### 3.9 工作项操作

- 新建事项：`Ctrl+N`。
- 从模板新建：`Ctrl+Shift+N`。
- 保存：`Ctrl+S`。
- 重复当前事项：`Ctrl+D`。
- 删除当前项：`Ctrl+Shift+D`。
- 同步当前工时：`Ctrl+U`。
- 批量同步当日工时：`Ctrl+Shift+U`。
- 工作项脚本：当前事项已保存且存在匹配脚本时显示；未保存事项对应脚本入口禁用并提示先保存。

### 3.10 锁定、只读和删除边界

- 已远程上传的 Tracker 绑定字段进入锁定状态，避免修改后与远程记录不一致。
- 从旧数据迁移导入且标记只读的事项只允许查看。
- 删除本地事项前进行确认。
- 删除本地事项不会删除已提交到远程 Tracker 的工时，界面会明确提示该边界。

### 3.11 标签自动化触发来源

- 用户手动添加标签。
- 从模板创建事项。
- 批量复制、复制最近、复制整天和重复事项。
- Tracker 规则自动补充默认 Issue、活动等字段。
- 单个 Tracker 实例规则失败不会阻断其他实例；冲突或无效目标会给出诊断。

## 4. 事项查询

### 4.1 查询条件

- 开始日期和结束日期。
- 今天、昨天、本周、本月等快捷日期，以及完整的上/本/下周、月、季度、年选择。
- 标题或备注关键词。
- 多标签选择。
- 标签匹配模式：忽略标签、任意标签、全部标签、无标签、精确匹配。
- 优先级筛选。
- 条件区域可显示或隐藏。
- 日期范围和条件组合在查询前执行标准化与校验。

### 4.2 查询结果

- 显示日期、事项标题、工时、优先级和标签摘要；每条结果可“打开”并跳回对应日记日期/事项。
- 显示结果条数、总工时、分组汇总和错误状态。
- 默认最多返回 200 条，达到上限时在摘要中提示。
- 支持把结果导出为 CSV。
- 支持把结果导出为 Markdown。
- 支持复制汇总文本。
- 数据库不可用或查询失败时保留上次结果并显示错误。

### 4.3 保存的查询

- 为当前条件新增命名查询。
- 应用已保存查询。
- 更新、重命名和删除查询；删除前确认。
- 保存日期、文字、标签匹配、优先级等条件。
- 保存标签快照；标签缺失或 ID、名称、层级不匹配时提示并跳过不可靠标签。

## 5. 统计工具

### 5.1 统计 Tab

- 支持上周、上个月、上季度、去年、这周、这个月、这季度、今年、自定义九种统计类型。
- 自定义统计 Tab 固定存在。
- 可从 Tab 头右键菜单增加预设统计类型。
- 可删除非自定义统计 Tab。
- 已打开的统计类型持久化。
- 可从日记日历上下文菜单快速打开对应范围统计。

### 5.2 范围和计算

- 自定义开始/结束日期。
- 快速选择上/本/下周、月、季度、年。
- 可设置占比计算基准总工时；为空时使用统计总工时。
- 手动刷新/重新计算。
- 数据库不可用时显示重试、数据库设置和诊断日志入口。

### 5.3 展示和明细

- 工时分布默认使用柱状图展示各主标签工时，可切换为带标签图例的饼图；两种图表复用同一次统计结果。
- 树形表格展示标签 ID、标签名、耗时、占比和操作。
- 支持主标签/次标签层级以及未分类工时。
- 支持展开全部、折叠全部和点击行切换层级。
- 可查看某个标签或标签组合对应的事项明细。

## 6. 调查工具

### 6.1 可用条件和帮助

- 调查服务未启用时不显示主导航页；服务对象不可用时显示不可用状态。
- 提供打开 `SurveyUserGuide.md` 的使用指南入口。
- 支持兼容查询和扩展查询两种模式。

### 6.2 查询条件

- 开始/结束日期及快捷日期范围；开始日期晚于结束日期时显示本地校验提示、禁用发起按钮且不发送调查请求。
- 兼容模式按日期范围调查。
- 扩展模式增加：标题或备注关键词、多个标签名、标签匹配模式、优先级、按标签/日期/优先级分组、是否返回结果明细。
- 扩展查询明细最多返回 500 条。
- 可指定占比计算基准并重新计算。

### 6.3 节点和结果

- 发起调查并显示“正在调查中”状态。
- 探测支持 v2 协议的新节点能力。
- 查看各节点支持的查询类型、分组维度和明细能力。
- 同时兼容旧协议响应和扩展协议响应。
- 按受访节点显示日期范围、总耗时、汇总方式、明细、标签树和错误。
- 结果区域支持纵向、横向滚动和层级展开；标签树默认折叠，只显示根节点，用户可按需展开子项。

## 7. 脚本管理和脚本编辑器

### 7.1 脚本工作台

- 新建脚本、导出脚本共享包、打开脚本目录、重新加载脚本目录。
- 按名称或稳定 ID 搜索。
- 按 Scope 和加载状态筛选。
- 列表显示语言、Scope、入口类型、状态和描述。
- 空目录和无搜索结果分别显示空状态。

### 7.2 脚本列表和上下文菜单

- 打开源码、打开所在目录、重新检查/重新编译加载、运行可运行脚本、删除脚本并确认。
- C#、Lua、Python 使用不同图标；是否真正可运行以当前引擎和加载诊断为准。

### 7.3 脚本详情

- 概览：名称、ID、语言、Scope、入口类型、状态、源码路径、描述和能力声明。
- 运行配置：Lua/Python 等元数据名称和描述、默认 `key=value` 参数、默认超时时间。
- 自动化配置：`daily HH:mm`、应用启动后补跑、工作项创建后/保存后/添加标签后触发。
- 保存或放弃运行配置修改。
- 查看当前脚本编译/加载诊断并复制诊断。
- 查看整个脚本目录诊断并复制。

### 7.4 执行历史和 API Reference

- 按执行状态和来源筛选会话内执行历史。
- 清空执行历史。
- 每次执行显示来源、状态、耗时、执行 ID、Worker ID、进度、效果和诊断。
- 复制单次执行日志。
- API Reference 可按语言和能力浏览宿主 API、参数及说明。
- 正在执行时显示进度条和进度消息，并可取消。

### 7.5 新建脚本

- 输入脚本名称、稳定 ID 和描述。
- Scope：应用脚本、编辑器脚本。
- 语言：C#、Lua、Python。
- API 版本：默认 V2（推荐），可选择 V1（兼容）；展开版本下拉框可查看参数契约差异和未来可能的弃用方向。
- 应用脚本样板：空白、工作项查询、查询脚本、自动化脚本。
- 编辑器脚本按编辑目标提供对应样板。
- 自动化脚本可配置定时、启动补跑及工作项事件触发；至少需要一种触发方式。

### 7.6 手动运行对话框

- 每行一个 `key=value` 执行参数；忽略空行和 `#` 注释行。
- 可填写幂等键和超时秒数。
- 可开启预览执行；预览模式阻止持久写入和真实文件导出，只执行查询、日志、投影结果和绑定预检。
- 显示参数校验错误。

### 7.7 脚本源码编辑器

- 独立窗口编辑源码，显示文件名和完整路径。
- 行号、水平/垂直滚动和等宽字体。
- API Reference、编译检查、保存、另存为、放弃修改、关闭。
- 编译/语义诊断列表，点击诊断跳转对应位置。
- C# 实时语义检查和悬停信息。
- 检测外部文件变化，可重新加载外部版本或覆盖保存。
- 有未保存修改时阻止静默关闭并要求处理。

### 7.8 脚本共享包

- 导出时支持全选、清空、选择脚本和选择保存位置；源码与同目录运行配置一起导出。
- 导入前检查包完整性、脚本列表和冲突。
- “只选无冲突项”；冲突项默认不选，主动勾选表示覆盖源码及运行配置。
- 明确提示共享包没有来源签名，只应导入可信脚本。
- 导入不会立即执行，但自动化脚本会参与后续调度。
- 导入后重新加载脚本，开发者功能关闭时仍可通过通知了解结果。

## 8. 程序设置和维护功能

### 8.1 通用设置编辑器

- 配置树按属性元数据动态生成。
- 支持分组/折叠、字符串、密码、字体、目录/文件、整数、小数、开关、选项、操作按钮和帮助 Tooltip。
- 打开当前日志、导出日志。
- 保存设置并立即应用字体、主题及需要动态刷新的页面。
- 关闭时重新加载已保存配置，放弃未保存修改。

### 8.2 视图设置

- 界面字体：内置字体、系统字体、已安装字体或 `.ttf/.otf` 文件；不可用时回退。
- 默认配色主题：Light、Dark、Auto。
- 始终显示托盘、隐藏到托盘、显示开发者功能。
- 重新打开首次使用引导。

### 8.3 工作设置

- 新建事项默认标题。
- 每天默认工作时长，用于工时目标和相关汇总。

### 8.4 数据库设置

- 选择数据库驱动。
- SQLite：选择数据库文件路径。
- PostgreSQL：服务器、端口、数据库、还原目标数据库、用户名、密码和工具目录。
- 保存数据库配置后重新连接；失败时回滚到旧配置。
- 创建数据库备份，包含核心数据和 Tracker 扩展表。
- 选择并校验备份；确认后暂存还原任务，在安全启动流程中执行替换。
- provider 不支持备份/还原或环境不满足时显示明确错误。
- 打开旧数据迁移向导。

### 8.5 数据迁移向导

- 选择源数据库类型。
- SQLite 选择源数据库文件。
- PostgreSQL 输入服务器、端口、数据库、用户名和密码。
- 开始迁移前提示会替换当前数据的风险。
- 迁移过程中禁用配置区，显示进度和阶段消息。
- 支持取消/中止。

### 8.6 调查设置

- 启用调查功能、是否作为调查者。
- 受访者填写调查者 IP 地址；固定协议端口由程序管理。
- 设置变更后重建调查服务对象和相关导航。

### 8.7 应用更新

- 配置局域网更新服务地址、更新频道（stable/preview/local）和安装包类型（Auto/standard/python313）。
- 开启或关闭启动后自动检查，并支持手动检查更新。
- 显示无发布版本、已是最新、新版本可用、更新器不支持、服务不可用和响应无效等结果。
- 下载、校验和准备更新，确认后重启应用。
- 更新后执行启动确认；失败时支持回滚流程。
- 本地修改与更新文件冲突时保留冲突文件，避免静默覆盖。

## 9. 标签、附加字段和自动化设置

### 9.1 标签列表和基础信息

- 新增标签：名称、主标签/次标签和颜色。
- 按名称即时过滤已有标签并浏览选择；列表显示标签名称、颜色、状态、附加字段数量和元数据数量，长名称使用省略显示，数量摘要单独换行，避免与删除操作重叠。
- 编辑标签名称、颜色、层级和启用/停用状态。
- 删除标签；危险操作使用明确样式和确认。
- 主标签约束在新增、修改、模板应用和工作项编辑时统一校验。

### 9.2 标签元数据

- 为标签添加任意键值元数据。
- 编辑元数据键和值。
- 删除单条元数据。

### 9.3 Tracker 自动化规则

- “自动化操作”Tab 由当前启用 Tracker 实例动态贡献规则编辑器。
- Redmine 规则在当前标签上下文中水平显示启用状态、活动、问题和删除操作，不重复显示已经由左侧列表确定的标签选择；Tracker 全局设置仍可选择标签。
- 标签保存时统一提交各 Tracker 的规则配置。
- Tracker 可为标签绑定默认 Issue、活动或其他目标。
- 无可用标签、目标失效、实例缺失或规则冲突时显示提示/诊断。

### 9.4 标签附加字段定义

- 新增和编辑字段。
- 配置显示名称、FieldKey、类型、说明、排序和启用状态。
- 新增或编辑字段确认后立即按排序值、FieldKey 升序重排，无需保存或重开标签设置。
- 单选项字段可按行维护选项。
- FieldKey 仅允许英文、数字、点、下划线和短横线。
- FieldKey 和字段类型创建后不可修改。
- 字段可停用而不删除历史值；有历史值的停用字段继续显示为字段级只读，没有历史值的停用字段不出现在工作项编辑器中。

### 9.5 标签导入/导出

- 导出前选择一个或多个标签，默认全选并支持全选/清空；共享包只包含所选标签的元数据、附加字段和 Tracker 规则描述。
- 导入前预览标签及冲突状态；冲突标签默认不可选。
- 把共享包中的 Tracker 来源映射到本地具体实例。
- 展示规则验证摘要和详情；无效或无法验证的规则不导入。
- 导入过程不暴露本地 Tracker 密钥。

## 10. 工作项模板和数据模板

### 10.1 工作项模板

- 新增和删除模板。
- 显示稳定模板 ID，并可复制 ID。
- 配置模板名称、默认标题、默认工时和默认标签。
- 模板标签选择遵守主标签约束。
- 从日记页“从模板新建”菜单应用模板。
- 应用模板前先保存当前有内容草稿。
- 模板添加的标签会触发标签自动化规则和相关应用脚本。

### 10.2 数据模板管理

- 导入 `.xlsx`、`.csv`、`.docx` 等插件支持的导出模板。
- 校验模板文件结构和数据绑定声明。
- 显示模板名、稳定 ID、版本/扩展名、处理插件和绑定摘要。
- 重新校验、启用/禁用、归档模板。
- 显示空状态、校验状态和错误。
- 支持标量、行、列和矩阵绑定标记。
- 模板本身不执行表达式，数据由脚本或宿主先准备后绑定。

## 11. Tracker 通用 UI

### 11.1 Tracker 设置对话框

- “Tracker 配置”Tab 按 provider 动态生成配置页。
- 每个 provider 可管理一个或多个实例。
- 保存前校验所有启用实例；无效配置阻止提交并显示错误。
- 保存后重建插件实例、日记编辑区和动态管理导航。

### 11.2 插件状态和生命周期

- 显示实例名称、实例标识、运行状态和错误信息。
- 加载失败时重试；启用或禁用实例。
- 保留扩展数据卸载实例，或删除扩展数据并卸载实例。
- 导出不含敏感值的诊断日志。
- 没有已注册实例时显示空状态。
- 保存配置并重建 Tracker 实例时，旧实例停止接收新请求；已经开始的 Redmine 请求持有客户端租约，完成后才释放底层 HTTP 客户端，避免配置重载与后台同步并发导致进程崩溃。

### 11.3 批量同步预览

- 真正远程写入前列出可同步记录。
- 显示标题、日期、Tracker 实例、工时和当前状态。
- 用户逐项选择是否同步。
- 已同步和结果不确定项默认不选且不可自动重试。
- 用户确认后才执行远程操作。

### 11.4 周/月快捷同步

- 日期右键菜单提供“同步本周工时”，年月周次按钮右键菜单提供“同步本月工时”。
- 执行前先自动保存当前有内容的未保存事项；保存失败时不启动远程同步。
- 按日期范围一次查询核心事项，并批量预取备注、标签、附加字段和各 Tracker 本地绑定。
- 只提交已保存、非迁移导入、尚未同步、没有同步中/结果待确认状态、工时大于 0，且所有待提交 Tracker 必填绑定完整有效的事项。
- 导入事项、已同步事项、同步中或结果待确认事项、0 工时、无 Tracker、绑定缺失或值失效的事项计入跳过，不调用远程 API。
- 执行期间显示范围、当前事项、处理进度及成功/跳过计数；任一 Tracker 或事项首次失败后立即终止，不继续处理后续 Tracker 和事项。
- 结束后显示成功、跳过、失败和未处理数量，按原因汇总跳过项；失败时给出日期、事项 ID、标题、Tracker 错误和剩余未处理数量。

## 12. Redmine UI

### 12.1 Redmine 实例配置

- 添加和删除多个 Redmine 实例。
- 实例列表显示显示名称和稳定实例 ID。
- 配置显示名称、导航图标、启用状态、服务地址和 API Key。
- 可选代理开关和代理服务器地址。
- API Key 使用密码型编辑器，不在普通文本或诊断中回显。
- 配置页内维护该实例的标签自动化规则。

### 12.2 Redmine 标签规则

- 添加/删除规则并逐条启用或停用。
- 为本地标签选择默认 Redmine 活动和默认 Issue。
- 没有启用标签时显示引导提示。
- 规则跟随具体 Redmine 实例隔离保存。

### 12.3 Redmine 工作项编辑区

- 选择已导入且启用的 Redmine Issue。
- 选择从服务器同步到本地的活动类型。
- Issue 列表显示 ID、标题和项目。
- 保存本地工作项后可追加 Redmine 工时。
- 已上传记录锁定并阻止重复提交。

### 12.4 Redmine 管理页：基本信息

- 管理页直接以“基本信息 / 问题管理 / 项目管理”页签表达当前位置，基本信息页不再重复显示页面说明卡。
- 服务器不可连接时显示设置检查提示。
- 展示当前用户 ID、登录名和用户名。
- 展示本地活动列表，并从服务器同步活动定义。
- 活动同步遇到配置重载导致的旧页面生命周期结束时会安静停止并记录日志，不会将异常抛到 UI 线程。
- 展示已导入 Issue：ID、描述、分配人、项目和关闭状态。
- 与服务器同步已导入 Issue 状态，重新抓取/刷新本地 Issue 列表。
- 本地启用或停用 Issue。
- 当前“删除”入口会提示暂不支持，不会删除 Issue。

### 12.5 Redmine 管理页：问题管理

- 按关键词搜索，输入框按 `Enter` 执行。
- 按问题 ID 搜索，输入框按 `Ctrl+Enter` 执行。
- 筛选“打开的问题”和“分配给我的”。
- 首页、上一页、下一页、尾页分页，并显示结果总数和总页数。
- 结果显示 ID、标题、项目、分配人、状态和优先级。
- 把远程 Issue 及所属项目导入本地共享列表。
- 重复导入不会破坏已有本地映射，导入后编辑器列表即时刷新。

### 12.6 Redmine 管理页：项目管理

- 按项目关键词搜索，`Enter` 或按钮执行。
- 首页、上一页、下一页、尾页分页，并显示结果总数和总页数。
- 显示项目 ID 和名称，支持查看项目说明。
- 在所选项目下创建新 Issue。
- 新建 Issue 输入标题、说明，并可按默认选项分配给当前用户；标题必填。
- 创建成功后显示远程 Issue ID，并可继续通过问题管理导入。

## 16. 条件可见、只读和安全边界

- 数据库不可用时，以恢复操作替代正常数据编辑，不把连接错误表现为空数据。
- 调查页只在调查者能力启用时出现。
- 脚本管理页只在开发者功能开启时出现；脚本扩展导入入口仍可独立使用。
- Tracker 管理页、设置页和编辑器 Tab 均由已启用实例动态贡献。
- 远程写入前保留本地数据，批量操作先预览，危险操作要求确认。
- 成功上传和结果不确定的远程记录不自动重复提交。
- 密码、API Key、Token 使用敏感编辑器和加密配置存储，日志/诊断不应记录明文。
- 用户手册入口只在 Release 编译且 `Docs/UserManual/DiaryApp-User-Manual.html` 或 `.pdf` 存在时显示；优先打开 HTML，缺失时回退 PDF。Debug 输出目录无需携带手册。
- Release 构建不包含 CDP UI 自动化组件；CDP 仅在 Debug 且显式配置端口时启用。
