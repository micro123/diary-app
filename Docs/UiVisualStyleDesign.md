# UI 视觉样式设计

## 1. 目标

DiaryApp 保留深色工作台和蓝色交互色，通过少量明确的页面模板统一标题、间距、按钮语义和状态表达。
视觉统一不要求所有页面使用相同结构：日记、查询和统计属于工作台；标签、Tracker 实例属于主从管理页；程序设置、模板、数据模板和 Tracker 设置属于模态管理页；Redmine 动态页面属于带页签的管理工作台。

本设计只调整视觉层级和交互语义，不改变数据库、脚本、Tracker 或远程同步行为。

## 2. 页面模板

### 2.1 工作台

适用于日记、工作项查询和统计：

- 日记使用固定宽度日期/事项主栏和可滚动详情栏，日期、事项列表、当天汇总保持独立层级；左侧日期导航固定显示一周，日期右键承载日/周操作，月份标题右键承载月/季度/年度操作，完整月历作为仅用于选择和定位的按需弹层；
- 工作项“一般信息”使用稳定标签列和内容列，日期、标题、耗时输入控件共享左边缘，紧凑按钮跟随所属输入控件；
- 查询使用页面标题、已保存查询、条件卡片和结果区，筛选折叠不改变结果可见性；
- 统计在每个统计页签内部使用一致的标题、范围、总计、图表和明细卡片；
- 页面主操作集中在标题或详情头部，危险操作与普通操作分组。

### 2.2 主从管理页

适用于标签、Jira 实例和 Redmine 实例：

- 左侧 `MasterPane` 承载新增、导入导出、列表和删除入口；
- 右侧 `DetailPane` 承载当前对象标题、状态、配置分组和附加规则；
- 列表显示稳定名称和必要的 ID/摘要，不在主栏堆叠完整设置；
- 详情超过可视高度时只滚动详情内容，底部保存/取消保持可达。

### 2.3 模态对话框

适用于程序设置、标签、模板、数据库、脚本运行和 Tracker 设置：

- 普通标题使用白色，不使用红色或绿色表达展开、选中等常规状态；
- 副标题使用较低对比度并允许换行；
- 底部操作区右对齐，顺序为中性操作在前、主操作在后；
- 红色只用于删除、清空数据和明确的不可逆放弃操作。

### 2.4 Tracker 管理工作台

适用于 Tracker 设置、插件状态和 Redmine 动态管理页：

- 保留外层“Tracker 配置 / 插件状态”和内层“Jira / Redmine”页签，维持用户认知和自动化契约；
- 插件状态以状态胶囊、错误卡片和普通/危险操作分组表达；
- Redmine 基本信息、问题管理和项目管理共用页面标题、工具栏、分页和表格容器；
- 编辑器内 Tracker 区域使用统一字段标签，并继续服从核心事项只读、已同步锁定和防重复提交边界。

## 3. 基础样式

公共样式位于 `Diary.GUIBase/Resources/AppStyles.axaml`：

| Class | 用途 |
| --- | --- |
| `PageTitle` | 标准页面或设置窗口一级标题 |
| `PageSubtitle` | 一级标题下方的简短说明 |
| `Header` | 需要居中的传统对话框标题，逐步迁移到统一颜色和字号 |
| `DialogFooter` | 右对齐的模态操作区 |
| `EmptyStateTitle` | 完整空状态或错误状态标题 |
| `EmptyStateDescription` | 空状态或错误状态说明 |
| `ToolbarCheckBox` | 工具栏中的 CheckBox 垂直对齐 |
| `PaginationText` | 分页区域文字垂直对齐 |
| `WorkspaceSection` | 工作台中的可展开内容分组 |
| `WorkspaceToolbar` | 工作台中的搜索、筛选和分页工具栏 |
| `PageHeader` | 页面或对话框的标题、说明和主操作容器 |
| `SectionCard` | 具有明确边界的设置、查询、统计或管理区块 |
| `SubtleCard` | 区块内部的次级说明、规则或错误信息 |
| `MasterPane` | 主从管理页左侧列表与新增操作区 |
| `DetailPane` | 主从管理页右侧详情或页面主要内容区 |
| `DetailHeader` | 详情对象名称、说明和状态摘要 |
| `StatusPill` | 保存、同步、插件运行等短状态摘要 |
| `SectionTitle` / `SectionDescription` | 区块标题与低对比度说明 |
| `FieldLabel` | 表单字段标签的统一字重和垂直对齐 |
| `PageActions` / `CompactActions` | 页面级和紧凑操作按钮组 |
| `IconAction` | 复制等仅图标紧凑操作 |

设置项继续复用 `SettingLineBox`、`SettingLineCaption` 和 `SLV`。设置分组展开时只使用蓝色强调，不使用成功色；内容分隔线使用普通边框色，不使用危险色。

## 4. 操作颜色语义

| 语义 | 样式 | 示例 |
| --- | --- | --- |
| 主操作 | `Primary` | 保存、创建、运行、查询、迁移 |
| 中性操作 | 默认按钮 | 取消、关闭、返回、重新加载 |
| 危险操作 | `Danger` | 删除、删除数据、清空、覆盖不可恢复内容 |

“禁用”是否使用危险样式取决于数据是否保留。保留数据且可以立即恢复的启停操作保持中性；会删除本地或远程数据的操作必须使用 `Danger`。

## 5. 文案规范

- 产品名称统一写作 `Redmine`，代码类型名暂不重命名；
- 凭据字段统一写作 `API Key`；
- “关闭”只表示退出页面，“删除”或“删除数据”明确表示数据影响；
- 错误提示应同时描述问题和下一步操作。

## 6. 自动化验收

CDP 视觉回归至少覆盖 1280×800 深色主题：

- 工具栏控件中心线偏差不超过 2px；
- 设置窗口最后一组仍为“AI 与 MCP”；
- 对话框底部操作区完整可见；
- DataGrid 操作列不被裁剪；
- 空状态、错误状态和只读状态没有重叠；
- 一周日历在 150% DPI 下无裁切；今天使用圆形浅色强调底与描边、当前选中使用圆形主色高亮背景，悬停和按下反馈同样保持圆形且可叠加；右键非选中日期后按钮保持稳定并打开菜单，日期与月份标题上下文菜单均可达，完整月历按模板自然测量，外层宽高不得小于内部模板，最后一行与四周边框完整可见且不承载右键操作；日期、标题和耗时输入框左边缘偏差不超过 1px；
- Redmine 样式检查只执行读取和页面导航，不创建 Issue、不导入问题、不提交工时。
- 固定宽度对话框中的标题、副标题、长 ID 和底部操作不得横向溢出；长详情必须通过局部滚动访问。
- `Name`、命令、快捷键、页签文字和关键按钮原文案属于自动化及兼容性契约，视觉重构不得随意改名。

## 7. 迁移顺序

1. 收敛公共样式、按钮语义、Redmine 命名和明确的对齐问题；
2. 统一日记、查询和统计工作台；
3. 迁移程序设置、标签、模板、数据模板和 Tracker 设置；
4. 统一 Jira/Redmine 实例配置、编辑区域及 Redmine 动态管理页；
5. 通过功能 CDP、只读视觉 CDP 和最终截图复检收口。
